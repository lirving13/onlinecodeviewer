JavaScript Basics: Variables, Functions & DOM

28 Apr 2025

JavaScript turns static pages into interactive experiences. In this guide, we’ll cover three fundamentals: variables and data types, functions, and DOM (Document Object Model) manipulation. By the end, you’ll have working examples to test in your Online Code Viewer editor.

1. Variables & Data Types

Declare variables using let (mutable) and const (immutable):

let username = "Alice";
const maxItems = 5;

JavaScript supports primitive types (string, number, boolean, null, undefined) and objects/arrays.

2. Functions

Functions encapsulate reusable logic. Here’s a simple function:

function greet(user) {
  return `Hello, ${user}!`;
}
console.log(greet(username)); // "Hello, Alice!"

Or arrow functions for brevity:

const add = (a, b) => a + b;
console.log(add(2,3)); // 5

3. DOM Manipulation

The DOM represents your HTML as a tree. Use querySelector to select elements:

const title = document.querySelector('h1');
title.textContent = 'Welcome to JS Basics';

Add interactivity with event listeners:

const btn = document.querySelector('.my-btn');
btn.addEventListener('click', () => {
  alert('Button clicked!');
});

Play around by modifying styles or adding/removing elements dynamically. These basics set the stage for frameworks like React, Vue, and Angular.
