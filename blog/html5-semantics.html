HTML5 Semantics: Building Accessible Markup

25 Apr 2025

Semantic HTML is about using tags that describe their meaning, making pages easier for browsers, search engines, and assistive technologies to understand. HTML5 introduced several new semantic elements—<header>, <nav>, <main>, <article>, <section>, and <footer>—which replace generic <div> blocks.

Why Semantics Matter

Screen readers use landmark roles to let users skip to a section. Search engines use headings and structure to index content. Good semantics = better accessibility + SEO.

Key HTML5 Elements

  • <header>: introductory content or site-wide/global navigation.
  • <nav>: primary navigation links.
  • <main>: main page content, unique per document.
  • <article>: self-contained composition, like blog posts.
  • <section>: thematic grouping within content.
  • <footer>: footer for a section or document.

Example Structure

<body>
  <header>…navigation…</header>
  <main>
    <article>
      <header><h1>Article Title</h1></header>
      <section>…content…</section>
    </article>
  </main>
  <footer>…site info…</footer>
</body>

By adopting these tags, you ensure your markup is meaningful—and you’ll see benefits in both accessibility tests and search rankings.
