CSS Basics: Selectors, Box Model & Flexbox

1 May 2025

1. CSS Selectors

Selectors let you target HTML elements for styling. Common types include:

  • element selector: p { color: blue; }
  • .class selector: .btn { padding: 1rem; }
  • #id selector: #header { background: #333; }
  • Attribute selector: a[target="_blank"] { color:red; }

2. The Box Model

Every element is a rectangular box composed of:

margin ↔ border ↔ padding ↔ content

Use box-sizing: border-box; to include padding/border in the element’s width/height.

3. Flexbox Layout

Flexbox makes one-dimensional layout simple:

 .container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Key properties:

  • justify-content: horizontal alignment
  • align-items: vertical alignment
  • flex-wrap: control wrapping

With these fundamentals, you can build responsive, flexible UIs.
