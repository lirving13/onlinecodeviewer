CSS Basics: Selectors, Box Model & Flexbox

1 May 2025

Cascading Style Sheets (CSS) is the language that makes the web beautiful. Before diving into complex frameworks, you need to understand three core concepts: selectors, the box model, and Flexbox. In this guide, we’ll cover each in turn, complete with code examples you can copy into your Online Code Viewer editor and experiment with instantly.

1. CSS Selectors

Select the right elements to style your page. Common selectors include:

  • element selector: targets tags—e.g., p { color: blue; }.
  • .class selector: targets class attributes—e.g., .btn { padding: 1rem; }.
  • #id selector: targets unique IDs—e.g., #header { background: #333; }.
  • Attribute selectors: a[target="_blank"] { color: red; } for links opening in new tabs.

Combine selectors for specificity: nav ul li a:hover { text-decoration: underline; }.

2. The Box Model

Every element is a box composed of content, padding, border, and margin. Use this CSS rule to include padding/borders within the element’s width/height:

*, *::before, *::after {
  box-sizing: border-box;
}

Example:

.card {
  width: 200px;
  padding: 1rem;
  border: 1px solid #ccc;
  margin: 1rem auto;
}

This ensures your layout calculations are predictable.

3. Flexbox Layout

Flexbox makes one-dimensional layouts intuitive. Wrap child elements in a flex container:

.flex-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Key properties:

  • justify-content: controls horizontal alignment (e.g., center, space-around).
  • align-items: controls vertical alignment (e.g., flex-start, stretch).
  • flex-wrap: allows wrapping onto multiple lines.

Flexbox is perfect for nav bars, galleries, and responsive card layouts.

Putting It All Together

Here’s a quick demo combining everything:

<div class="flex-container">
  <div class="card">Item 1</div>
  <div class="card">Item 2</div>
  <div class="card">Item 3</div>
</div>

Copy this into your editor to see real-time results. Master these basics, and you’ll be ready to explore Grid, animations, and advanced layouts.
